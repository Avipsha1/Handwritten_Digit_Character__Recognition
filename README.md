# Handwritten Digit and Character Recognition System

## Project Overview
This project focuses on recognizing handwritten digits (0–9) and uppercase English alphabets (A–Z) using a Convolutional Neural Network (CNN).

## Technologies Used
- Python
- TensorFlow and Keras
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Features
- Handwritten digit recognition (0–9).
- Uppercase alphabet recognition (A–Z).
- Image preprocessing using OpenCV.
- CNN-based classification.
- Single-character prediction.
- Multiple-character recognition.

## Project Files
- `Handwritten_Digit_Character_Recognition.ipynb` – Complete project notebook.
- `handwritten_recognition_model.keras` – Trained CNN model.
- `README.md` – Project description.
- `requirements.txt` – Required Python libraries.

## How to Run
1. Open the notebook in Google Colab.
2. Install the required libraries.
3. Run the notebook cells sequentially.
4. Upload a handwritten digit or uppercase character to test the model.

## Dataset
- MNIST Dataset
- EMNIST Letters Dataset
